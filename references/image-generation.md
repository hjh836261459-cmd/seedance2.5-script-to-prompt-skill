# 角色图、场景图与首帧图

当用户缺少稳定参考素材时，先规划要生成的静态图片，再写视频提示词。不要假设某个固定图片模型或平台；按用户可用工具输出通用图片提示词。

## 角色参考图

目标是身份和服装可重复，而不是做海报。

至少准备：

- 正面中性表情近景：锁五官、发型、肤质。
- 正面或四分之三侧全身：锁身材、服装、鞋和配饰。
- 必要时增加侧面或背面：用于大幅走位、打斗或换角度。

所有视图保持年龄段、脸型、发型、服装层次、配饰、体型和色彩一致。背景简单、光线中性、无遮挡、无文字。不要在一张参考图里混入不同服装方案。

模板：

```text
[角色身份与年龄段]，[脸型、五官、肤质、发型]，[身材比例]，
穿[服装款式、层次、材质、颜色与磨损状态]，佩戴[配饰]。
[正面/四分之三侧/全身]角色定妆参考图，中性自然站姿，双手可见，
柔和中性光，纯净背景，真实比例，细节清晰，无文字、Logo、水印或场景道具。
```

## 场景参考图

锁定时间、天气、空间轴、主光方向、材质和关键物体位置。为会反复出现的房间、街道、店铺或产品台建立一张广角空间图，再补需要的反向视角。

模板：

```text
[时间、地点、天气]，[空间布局和关键物体位置]，[主光来源和方向]，
[墙面、地面、家具/建筑材质]，[色彩和反差]，[画幅和广角视角]。
用于场景连续性参考，空间关系清楚，无人物、无文字、无水印。
```

## 风格参考帧

优先准备同一视觉规则下的近景、中景和广角各一张。必须包含真实的阴影、中间调、高光和必要肤色；不要只做纯色色卡。详见 `aesthetic-constraints.md`。

## 首帧图

首帧必须同时满足：视频目标画幅、正确角色与服装、可运动的起始姿态、足够的画外空间、明确主光方向、无字幕/UI/水印。

不要把高潮姿态误作首帧，除非视频从高潮开始；不要裁掉即将运动的手脚、产品或道具。

模板：

```text
[视频画幅]电影分镜首帧。[角色]在[场景]处于[可运动的起始姿态]，
[景别、机位、方位、焦段感和构图]，[光线、色彩、材质和风格]。
为[运动方向]保留画外空间，角色和关键道具完整，无文字、字幕、Logo、水印或界面。
```

## 尾帧图

尾帧用于首尾帧控制或下一镜衔接。必须与首帧在身份、服装、场景、天气和光线逻辑上兼容，动作链能够从首帧自然到达。

## 质量检查

- 人物是否为同一身份与服装版本。
- 手、脚、产品和关键道具是否完整。
- 场景轴线和主光方向是否明确。
- 图片比例是否与目标视频一致。
- 首尾状态是否物理可达。
- 是否不存在字幕、UI、水印和随机文字。
