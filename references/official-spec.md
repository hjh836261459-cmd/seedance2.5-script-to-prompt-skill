# Seedance 2.5 官方手册规格

本文件是本 Skill 的参数与能力真值表。若用户当前界面显示不同，以界面为准并说明差异。不要引用 Seedance 2.0 的旧限制。

## 输入与时长

| 类型 | 限制或建议 |
|---|---|
| 普通生成 | 4–30 秒 |
| 超长视频 | 30–180 秒 |
| 视频延长 | 原视频不超过 30 秒；新增 4–30 秒；合成结果最长 60 秒 |
| 图片 | 最多 30 张；优先清晰、主体无遮挡的 4K 图片 |
| 视频 | 最多 10 条；单条 2–30 秒；全部视频总时长不超过 30 秒 |
| 音频 | 最多 10 条；单条 2–30 秒；全部音频总时长不超过 30 秒 |
| 纯音频输入 | 支持 |
| 清晰度 | 480p 或 720p；默认建议 720p |

不要把“图片 30 + 视频 10 + 音频 10”简化成未经说明的“任意 50 个素材”；三类素材各自有规则。

## 稳定性建议

以下是实践建议，不是硬限制：

- 音频或视频驱动时，主体优先 1–5 个，参考片段优先 5–10 秒。
- 图片驱动时，主体优先 1–8 个。
- 视频编辑源优先不超过 20 秒。
- 高级局部编辑优先使用 1–5 张清晰参考图。
- 复杂多人动作、连续形变、长对白和高速镜头应拆短。

## 模式路由

| 任务特征 | 推荐模式 | 要点 |
|---|---|---|
| 文字或常规参考素材 | 普通多模态生成 | 拆成 4–30 秒单元 |
| 必须固定第一帧 | 首帧控制 | 首帧作为构图与状态锚点 |
| 必须固定开头和结尾 | 首尾帧控制 | 解释从 A 到 B 的连续变化 |
| 单一连续事件，30–180 秒 | 超长视频 | 少人物、少地点、完整时间轴 |
| 原视频接着演 | 视频延长 | 锁定原视频最后一帧状态 |
| 原视频换人、换物、删除或局部修改 | 智能编辑 | 分开写保留项、修改项与时间段 |
| 精细替换或局部控制 | 高级局部编辑 | 用 1–5 张图定义对象和边界 |
| 保留动作但换内容或视觉方向 | 创意迁移 | 分开绑定动作与新内容/风格 |
| 复刻镜头路径 | 运镜参考 | 视频只负责相机轨迹 |
| 复刻声音 | 音色/音频参考 | 写明说话人、语种、语气和用途 |
| 独立抠像素材 | 绿幕生成 | 均匀纯色背景，边缘清晰 |
| 3D 预演转成片 | 粗白模/精白模 | 锁空间、站位、动作与机位 |
| 两段素材连接 | 无缝转场 | 使用一个主要共同锚点 |
| 多镜头概念预览 | 多宫格分镜 | 正式成片仍建议逐格生成 |

## 官方能力范围

- 纯文本、首帧、首尾帧、多模态与纯音频驱动。
- 写实人物、动画角色、多人互动、动作与舞蹈。
- 4–30 秒普通生成、30–180 秒超长生成、时间戳控制。
- 一镜到底、视频延长、智能编辑与高级局部编辑。
- 去除 BGM、干净画面、旁白与对白控制。
- 创意迁移、视角改变、音色参考与绿幕生成。
- 粗白模、精白模、无缝转场与多宫格分镜。
- 产品广告、短剧、教育科普与多语言内容。

不要加入“写实人脸不支持”或“必须认证才能使用写实人物”等手册未给出的旧版/第三方限制。

## 素材引用规则

每个引用都包含对象、用途、范围和排除项：

> 以 `@图片1` 锁定女主五官、短发和红色风衣，用于 S01–S06；只参考人物外观，不沿用背景与文字。以 `@视频1` 只参考环绕运镜的速度和轨迹，不复制人物与场景。

避免只写“参考 @图片1 和 @视频1”。

## 复杂度预算

一个普通生成单元优先只包含：

- 1 个核心叙事目标。
- 1 个主要地点。
- 1 次清晰情绪转折。
- 1 条主要运镜路径。
- 1–3 个连续动作节点。
- 一小段自然长度的对白或旁白。

## 连续性锚点

- 人物：脸型、发型、服装、配饰、伤痕、手持物、情绪余韵。
- 场景：时间、天气、光线方向、空间方位、关键物体位置。
- 动作：上一镜结束姿态、视线、运动方向和速度。
- 声音：说话人音色、环境底噪、音乐节拍和前一镜尾音。

不要只写“保持一致”，要指出保持什么一致。
