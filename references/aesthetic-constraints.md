# 可观察的美学约束与风格锁定

目标是把“电影感”“高级感”改写为模型能够观察和执行的画面规则。不要靠 8K、某渲染器、某摄影机或“大片感”等品牌/规格词堆砌质量。

## 风格卡公式

`题材 + 年代地域 + 美术与服装 + 光源 + 光的行为 + 色彩/反差 + 焦段/景深 + 画幅 + 材质/肤质 + 相机稳定性 + 表演 + 禁止项`

示例：

```text
欧洲现实主义冬季剧情片，现代北方小城，朴素冬装与灰色混凝土环境。
阴天自然漫射光，中性偏冷白平衡，灰蓝和灰绿低饱和色调，低至中等反差，
高光平缓不过曝。平视中近景，70–85mm 长焦感，浅景深，轻微自然手持呼吸。
保留毛孔、眼袋、泪痕和衣物纤维，演员表演克制，以停顿、呼吸和视线表达情绪。
不使用橙青商业调色、磨皮、塑料肤质、强轮廓光或夸张哭喊。
```

## 光影三层

1. 光源：光从哪里来，是什么光。例如阴天漫射天光、窗外侧光、烛火、霓虹、夕阳侧逆光。
2. 光的行为：光如何作用于材质和空气。例如烟雾散射、雨水反光、皮肤柔和高光、金属硬反射、树叶形成斑驳影。
3. 色彩与反差：主色、辅助色、肤色、黑位和高光。例如冷灰低饱和、暖金与墨绿、中高反差、柔和黑位。

“体积光、丁达尔效应、镜头耀斑、雨滴粘镜”等只能在场景存在对应物理条件时使用。

## 构图与画面层次

- 主体层：人物、产品或核心动作必须清晰。
- 前景层：树叶、门框、烟雾或物体形成视差与遮挡，但不遮住关键动作。
- 背景层：承担空间信息和色彩，不随机改变结构。
- 留白：用于孤独、产品聚焦或字幕后期空间；不是所有画面都需要 30% 留白。
- 元素预算：简洁广告和强概念镜头优先 1–3 个核心元素；群像和世界观镜头可增加，但要明确主次。

## 材质与真实感

用可见细节写材质：

- 人物：毛孔、雀斑、眼袋、细纹、泪痕、发丝边缘、布料纤维。
- 金属：划痕、氧化、油污、水珠、边缘磨损与环境反射。
- 玻璃：厚度、折射、指纹、灰尘和高光形状。
- 食物：水分、油脂、蒸汽、切面纤维和受热变化。
- 动画/CG：模型比例、轮廓、贴图、材质粗糙度、光照与动作风格。

不要同时要求“真实毛孔”和“瓷器般无瑕皮肤”等冲突特征。

## 常用电影风格锚点

| 风格 | 关键锚点 |
|---|---|
| 欧洲现实主义 | 自然/阴天光、低饱和、真实肤质、50–85mm、克制表演、轻微手持 |
| 清冷文艺片 | 冷灰或灰绿、负空间、缓慢微移、柔和黑位、安静环境声 |
| 东方古装田园治愈 | 暖金逆光、米白浅粉服装、森林墨绿、炊烟体积光、中长焦浅景深 |
| 英伦时代剧 | 烛光或窗光、暖金/象牙白/深黑、胶片颗粒、古典美术和克制礼仪 |
| 黑色电影 | 低调硬光、高反差、深黑阴影、百叶窗/雨夜、静态或缓推 |
| 写实悬疑 | 冷中性色、实景光源、负空间、35–50mm、缓慢侧移与声音先行 |
| 赛博朋克 | 夜雨、霓虹反射、冷蓝与品红、湿润材质、深景与前景遮挡 |
| 硬科幻 | 工业结构、真实金属和机械运动、冷白功能光、广角空间、物理因果 |
| High Fantasy | 宏大建筑/自然、逆光与体积雾、主辅色明确、广角揭示、尺度对比 |
| 写实纪录片 | 现场自然光、35mm、深景/中等景深、观察式机位、真实环境音 |
| 复古胶片 | 指定年代、美术与服装，柔和高光、适量颗粒、轻微色偏，避免泛滥刮痕 |
| 2D/三渲二动画 | 明确线条、上色、帧感、轮廓和光影规则，禁止写实塑料 3D 漂移 |

不要依赖在世导演、演员、品牌或受版权保护 IP 的名字锁定风格；拆成可观察特征。

## 风格锁定素材包

一张画面可锁单个短镜头的方向，多镜头项目优先：

- `@图片1`：人物近景，锁肤质、高光和景深。
- `@图片2`：中景，锁整体色彩、反差和主光方向。
- `@图片3`：环境广角，锁天气、空间材质和背景色。
- 角色定妆图：单独锁五官、服装和比例。
- 5–10 秒参考视频：只锁相机运动或表演节奏。

所有风格帧必须同源或同一视觉规则；去掉字幕、UI、播放按钮和水印。不要混合不同时间、天气和调色。

绑定示例：

```text
以@图片1至@图片3只锁定冷灰低饱和调色、阴天漫射光、真实肤质、
长焦浅景深与柔和高光，不复制人物、服装、建筑、动作、文字或具体构图。
```

## 色卡的边界

色卡可以锁定色相、饱和度和明暗方向，不能单独锁定光线质量、焦段、景深、肤质、颗粒、相机运动或表演。优先使用同时含肤色、阴影、中间调和高光的干净调色参考帧，而不是只有几个纯色块。

## 跨镜头稳定流程

1. 先生成最能代表全片的基准镜头。
2. 导出无文字的干净基准帧，作为后续镜头风格参考。
3. 每镜原样重复同一段风格锚点，不随意换近义词。
4. 连续动作使用上一镜尾帧作为下一镜首帧。
5. 固定天气、时间、主光方向、镜头范围和表演规则。
6. 后期统一曝光、白平衡、对比度、饱和度和颗粒。

参考素材与提示词能提高一致性，但不能保证数值级完全锁死；需要精确统一时必须后期调色。
