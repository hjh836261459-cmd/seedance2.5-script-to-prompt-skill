# 分镜板驱动

用于多宫格故事板、漫画、连续分镜图或白模分镜。先判断格间关系，再决定单条生成还是逐格生成。

## 1. 分析每格

为每格记录：

- 格号与阅读顺序。
- 角色、场景、时间和动作。
- 景别、机位、构图和视线方向。
- 台词、旁白、声音和情绪。
- 与上一格共同的角色、道具、动作、空间或光线锚点。
- 是否出现格线、编号、对白框、字幕或 UI。

## 2. 判断格间关系

| 类型 | 特征 | 推荐处理 |
|---|---|---|
| 连续动作 | 同一角色、地点、时间，动作自然延续 | 少格可用单条时间戳；复杂时逐格 |
| 连续叙事 | 有切镜但剧情、空间或声音连续 | 逐镜生成，明确衔接点 |
| 独立蒙太奇 | 地点、时间或画风不同，靠主题/情绪关联 | 逐格生成，后期按节奏拼接 |

## 3. 模式选择

- 2–4 格、单一地点、动作简单：可用 4–30 秒单条时间戳。
- 5 格以上、多人对白、跨地点或镜头差异大：每格独立生成。
- 30–180 秒且所有格描述同一连续事件：可评估超长模式，但仍要按阶段写时间轴。
- 多宫格只用于预览时：生成分镜板，不把格线和编号带入正式成片。

格数不是唯一标准；任务复杂度优先。

## 4. 格线和排版防护

```text
@图片1是分镜板，仅用于理解每格的构图、角色、动作和镜头顺序。
正式视频为单一全画幅画面，不复制宫格边框、分隔线、编号、对白框、字幕、注释、页边或排版。
```

## 5. 单条时间戳模板

```text
以@图片1的第1至第[数量]格作为镜头顺序和构图参考，不复制格线、编号或文字。
生成[时长]秒连续视频，[角色、场景和风格锚点]。
0–[x]秒：对应第1格，[动作、景别、运镜、声音]。
[x]–[y]秒：通过[动作/视线/遮挡/声音]转到第2格，[内容]。
……
[最后时间段]：对应最后一格，[收束与结尾状态]。
```

## 6. 逐格模板

```text
@图片1的第[K]格只负责本镜构图、人物站位和动作意图，不复制格线、编号、对白框或文字。
以[角色参考]锁定人物，以[场景参考]锁定空间和光线。
[时长]秒，[画幅]。[本镜目标]。
[动作、运镜、声音、结尾衔接和禁止项]。
```

## 7. 蒙太奇

独立格之间用一个主要共同锚点连接：颜色、形状、动作方向、声音、构图或主题意象。不要强行让不同画风和不同空间在生成阶段变成连续物理场景；逐格生成后剪辑更稳定。

## 8. 自检

- 阅读顺序是否正确。
- 每格是否都有镜头归属。
- 格线、编号、对白框和文字是否明确排除。
- 连续镜头的左右关系、动作方向和道具位置是否一致。
- 每格时间是否足够完成动作和台词。
- 独立场景是否选择了合理的剪辑锚点。
