# 相机四维编码系统

用坐标思维设计镜头，再把编码翻译成自然语言提示词。编码只用于规划，不要求直接写进 Seedance。

## 总公式

`镜头 = Z距离 + Y高度 + X方位 + F光学/叙事属性 + 运动 + 节奏 + 稳定约束`

## Z：景别与信息量

| 编码 | 景别 | 画面范围 | 适用 |
|---|---|---|---|
| Z1 | 大特写 ECU | 瞳孔、指纹、伤口 | 线索、极端感官 |
| Z2 | 特写 BCU | 眼睛、嘴、手 | 局部动作 |
| Z3 | 近景 CU | 完整面部 | 情绪与反应 |
| Z4 | 中近景 MCU | 胸口以上 | 对话、口播 |
| Z5 | 中景 MS | 腰部以上 | 手势、交互 |
| Z6 | 四分之三身 MLS | 膝盖以上 | 站姿、重心 |
| Z7 | 全景 FS | 完整人体与环境 | 舞蹈、动作 |
| Z8 | 远景 LS | 人小景大 | 环境关系 |
| Z9 | 大远景 ELS | 城市、山脉、战场 | 世界观与规模 |

## Y：机位高度与心理关系

| 编码 | 机位 | 效果 |
|---|---|---|
| Y7 | 垂直顶视 | 地图、秩序、全知 |
| Y6 | 俯视 | 弱小、被困、孤独 |
| Y5 | 轻微俯视 | 客观观察 |
| Y4 | 平视 | 平等、自然、默认 |
| Y3 | 轻微仰视 | 尊重、力量 |
| Y2 | 仰视 | 压迫、英雄、威胁 |
| Y1 | 虫视 | 巨物、神性、超现实 |

## X：主体方位

| 编码 | 方位 | 效果 |
|---|---|---|
| X1 | 正面 0° | 直接、凝视、口播 |
| X2 | 四分之三侧约 45° | 立体、自然、通用 |
| X3 | 侧面 90° | 轮廓、对峙、运动方向 |
| X4 | 背面 180° | 留白、未知、跟随 |

## F：镜头属性

### 焦段与空间

| 焦段 | 空间表现 | 常见用途 |
|---|---|---|
| 18–24mm | 开阔、边缘拉伸明显 | 建筑、狭小空间、宏大动作 |
| 35mm | 自然且保留环境 | 纪实、街头、走位 |
| 50mm | 接近经典叙事视角 | 对话、剧情 |
| 70–85mm | 空间压缩、背景虚化 | 人像、亲密、情绪 |
| 135mm+ | 强压缩、远距观察 | 窥视、远距跟拍 |

同时说明景深：浅景深、深景深、焦点转换、微距或变形宽银幕光学。焦段是创作近似，不承诺模型精确模拟真实镜头刻度。

### 叙事身份

- POV：第一人称代入。
- OTS：过肩对话，建立双方关系。
- Voyeur：透过门缝、窗、栏杆观察。
- Reflection：镜面或水面反射。

### 构图

- 对称居中：仪式、秩序、压迫。
- 引导线：走廊、道路、铁轨指向目标。
- 框中框：门窗形成束缚或窥视。
- 负空间：主体偏角，大量留白。
- 荷兰角：明确轻微倾斜，用于失衡；不要滥用。

## 运镜词典

| 运镜 | 描述重点 |
|---|---|
| 推进/拉远 | 起止景别、速度、主体是否保持居中 |
| 升降 | 起止高度、揭示对象、是否同时改变景别 |
| 横移 | 左右方向、速度、前景视差 |
| 摇摄/俯仰 | 扫描方向、停止对象 |
| 跟拍 | 主体方向、相机相对位置、距离是否固定 |
| 环绕 | 角度范围、半径、速度、背景结构稳定性 |
| 拉焦 | 焦点从什么转到什么、触发时点 |
| 甩镜 | 起止对象、模糊方向、转场落点 |
| 手持 | 轻微自然呼吸或强烈震动，必须二选一 |
| 一镜到底 | 明确完整空间路径与每个节点 |

| 情绪 | 推荐组合 |
|---|---|
| 压迫/危险 | Z3 + Y2 + X1，70–85mm，缓慢推近，低调光 |
| 孤独/渺小 | Z8 + Y6 + X4，广角，缓慢拉远，冷色 |
| 混乱/紧急 | Z5 + Y4 + X2，35mm，受控手持跟拍 |
| 浪漫/回忆 | Z4 + Y4 + X2，70–85mm，缓慢微移，柔和散景 |
| 宏大/揭示 | Z9，广角，深景深，升起或拉远 |
| 治愈/宁静 | Z5 + Y4 + X2，50mm，固定或微移，柔和自然光 |
| 悬疑 | Z4 + X3，35–50mm，缓慢侧移或拉焦，负空间 |
| 英雄/力量 | Z6 + Y2 + X1，24–35mm，低机位缓推 |
| 悲伤/克制 | Z3 + Y4/Y5 + X2，50–85mm，固定或微推 |
| 窥视 | Z3 + X3，长焦，前景遮挡，固定机位 |

## 多镜头递进

- 远到近：Z9 → Z5 → Z3，用于环境建立到情绪聚焦。
- 静到动：固定 → 缓推 → 跟拍，用于积蓄到爆发。
- 客观到主观：全景 → 过肩 → 特写/POV，用于进入角色内心。

不要机械套用；递进必须服务剧情。

## 冲突检查

- 一个镜头优先单轴或双轴运动；三轴同时大幅变化时拆镜。
- Z1–Z3 近景避免大幅环绕，防止脸部和背景形变。
- 文本方向必须与参考视频一致。
- 不同时要求推进和拉远，除非明确采用 dolly zoom。
- “固定机位”不能同时配大幅横移或环绕。
- “缓慢”和“快速”不能同时修饰同一段运动。
- 多人对话遵守 180° 轴线，明确左右站位和视线方向。

## 多模态分工

```text
以@图片1锁定角色外观，不沿用背景；以@图片2锁定场景结构与光线；
以@视频1只参考相机从中景平视缓慢推进到近景的速度和轨迹，不复制人物与场景。
```

参考运镜视频优先 5–10 秒、运动单一、起止清楚、无无关变速。最终提示词必须把编码翻译为完整的景别、机位、焦段、方向、速度和落点。
