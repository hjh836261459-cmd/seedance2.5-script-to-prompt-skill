# Seedance 2.5 专项提示词模式

只使用当前任务对应的模板，并把占位符换成具体内容。模板用于组织信息，不应机械照抄。

## 基础多模态镜头

```text
以@图片1锁定[角色/产品]的[特征]，仅参考[范围]，不沿用[背景/文字]；
以@视频1只参考[动作/运镜]，不复制[人物/场景]；
以@音频1作为[角色/旁白]的[内容/音色/节奏]参考。

[时长]秒，[画幅]。[主体]在[场景]完成[核心目标]。
[人物、环境、光线、色彩、焦段、景深、质地和风格]。
0–[x]秒：[景别、动作、运镜、焦点和声音]。
[x]–[y]秒：[动作与情绪变化、运镜和声音]。
[y]–[结束]秒：[收束动作、结束构图和衔接点]。
[说话人]用[语气]说：“[台词]”。保留[环境音/动作声]，[音乐要求]。
保持[具体连续性锚点]。不生成[相关禁止项]。
```

## 30 秒连续叙事

```text
生成30秒连续视频，[画幅、风格、角色与场景锚点]。
0–4秒：[建立或钩子]。
4–9秒：[触发事件]。
9–15秒：[反应与台词]。
15–22秒：[主要行动]。
22–27秒：[转折或结果]。
27–30秒：[收束和结尾状态]。
[声音设计、连续性和禁止项]。
```

阶段数量可在 4–7 段间调整，每段只推进一件事。

## 30–180 秒超长视频

```text
生成[时长]秒连续视频，[画幅和风格]。全程保持[角色外观、服装、道具、空间轴、光线方向和声音]。
0–15秒：[开场]。
15–30秒：[发展]。
30–45秒：[发展]。
……
[高潮时间段]：[高潮或核心展示]。
[最后时间段]：[收束与最终画面]。
阶段通过[动作/视线/遮挡/声音]衔接，不瞬移、不无故换装、不无故改变时间天气。[声音和禁止项]。
```

地点或角色状态发生重大变化时改为逐镜生成。

## 一镜到底

```text
生成[时长]秒一镜到底视频，全程无剪切、无跳帧、无瞬移。
相机从[起始位置和景别]开始，沿[路径]以[速度]移动，依次经过[空间节点]，
保持[主体]的空间连续性和动作因果。焦点从[对象A]自然转到[对象B]，
最后停在[结束构图]。[对白、环境音和禁止项]。
```

路径过于复杂时拆为多个伪一镜到底镜头，用遮挡转场拼接。

## 首尾帧控制

```text
以@图片1作为第一帧，锁定[起始构图、人物姿态和光线]；
以@图片2作为最后一帧，达到[结束构图、人物状态和物体位置]。
在[时长]秒内让[主体]通过[连续动作链]自然完成变化。
相机[运镜路径]，变化符合物理逻辑，不突然变形或瞬移。[声音设计]。
```

## 视频延长

```text
在@视频1结束后延长[4–30]秒。以原视频最后一帧为起点，保持[人物、服装、姿态、运动方向、相机速度、焦距、光线和环境声]。
0–[x]秒：[先承接上一状态]；[x]–[结束]秒：[新增动作与剧情]。
不要重演原片，不跳回较早状态，最终停在[结尾画面]。
```

遵守官方规格：原视频不超过 30 秒，新增 4–30 秒，合成结果最长 60 秒。

## 智能编辑与局部替换

```text
编辑@视频1。必须保留：[时长、运镜、背景、未修改人物、声音等]。
仅在[时间段/区域]把[原对象/属性]改为[目标]；以@图片1锁定替换对象的[外观]。
替换对象继承原对象的动作、透视、光照、遮挡和运动模糊。
其他区域不改变，不新增元素。
```

去除 BGM：

```text
移除@视频1中的背景音乐，保留对白、环境声和动作声；自然补齐缺失的环境底噪，
不改变画面、口型、台词节奏、字幕或其他声音。
```

## 创意迁移、动作与运镜复刻

```text
以@视频1只参考[动作/舞步]的节奏、幅度和时间点，不复制人物、服装和背景；
以@视频2只参考相机的[轨迹、速度、焦距变化]。
让@图片1中的角色在[场景]完成对应动作，保持脸部、服装和肢体比例稳定。
动作与[音乐/节拍]在[时间点]同步，以[结尾姿势]衔接下一镜。
```

复杂动作拆为起势、发力、腾空/转向、落地和定格，分别说明重心与方向。

## 多人对话

```text
[时长]秒，[场景与人物站位]。A位于[位置]，B位于[位置]，保持视线轴和左右关系。
0–[x]秒：A做[动作]，看向B，用[语气]说：“[台词]”；B只做[反应]。
[x]–[y]秒：镜头[切换/移动]到B，B用[语气]说：“[台词]”；A保持[动作]。
[y]–[结束]秒：[反应与结尾]。
音色分别绑定[参考]，口型对应各自台词，不串词、不抢话、不改变站位。
```

台词密集时拆为正反打镜头。

## 产品广告

```text
以@图片1锁定产品外形、材质、比例、Logo位置和包装颜色，不改字、不变形。
生成[时长]秒[画幅]广告。
0–[x]秒：[需求/氛围]；[x]–[y]秒：[产品出场和高光变化]；
[y]–[z]秒：[可见功能演示]；[z]–[结束]秒：[英雄镜头与收束]。
反射符合环境，手部接触真实。精确包装小字和最终 Logo 后期叠加，不生成随机文字。
```

## 教育科普

```text
用[时长]秒解释[概念]，受众为[受众]。先用[生活化问题]建立直觉，
再按因果顺序展示[可视化过程]，最后用[结论]收束。
旁白：“[原文]”。画面只出现与当前句对应的对象；公式、标签和大量文字后期叠加。
```

## 音色与纯音频驱动

```text
以@音频1作为[角色/旁白]的[内容、音色、语速、情绪和停顿]依据。
[人物]在对应语句自然口型同步，无台词处保持呼吸和微表情。
根据声音中的[节拍/情绪/关键词]安排动作与运镜。不改变原音频内容，不新增说话人。
```

只参考音色时明确“不沿用原音频台词”。

## 绿幕

```text
生成[主体]的独立绿幕素材，[时长]秒，[景别/机位]。
背景为均匀纯绿色，无渐变、阴影或纹理。主体完成[动作]，边缘和全身保持完整，
头发与半透明区域稳定，无绿色溢色。相机[固定/明确运镜]，不添加字幕或其他对象。
```

## 粗白模与精白模

```text
将@视频1的白模动画渲染为最终成片。严格保留空间布局、人物站位、物体尺度、
相机路径、动作时序和遮挡关系；只添加[角色/场景/材质/光影/声音]。
不改变白模的机位、路径、动作方向和时长。
```

粗白模用于空间和机位；精白模还锁角色轮廓、服装体块、产品结构、手部接触与遮挡。

## 两视频无缝转场

```text
以@视频1为前段，@视频2为后段，在[时长]秒内连接。
使用前段结尾的[运动/形状/颜色/遮挡/声音]作为唯一主要转场锚点，
通过[动作匹配/遮挡擦镜/形状匹配/甩镜/声音桥]变为后段开头的[对应元素]。
保持方向和速度连续，不出现黑帧、闪断、重影或主体形变。
```

## 多语言

```text
[角色]使用[语言/口音]自然说：“[原文台词]”，语气[描述]，语速[描述]，
口型与该语言发音同步。非必要文字不生成；翻译字幕后期添加。专有名词按[读法]发音。
```
