# 生成与剪辑节奏

节奏是时间轴上信息密度、动作强度、景别和声音的变化规律。它既可用于多片段后期，也可用于单条 30–180 秒视频的时间戳设计。

## 六种节奏曲线

| 曲线 | 结构 | 适用 |
|---|---|---|
| 呼吸式 | 快—快—慢—留白 | 日常、Vlog、轻剧情 |
| 心跳式 | 稳定脉冲逐渐加快 | 悬疑、运动、追逐 |
| 海浪式 | 小起伏—大起伏—高潮—平静 | 情感、MV、品牌故事 |
| 子弹时间 | 正常—减速聚焦—瞬间爆发 | 动作高潮、产品揭晓 |
| 脉冲式 | 成组快切—短停—更强一组—落点 | 预告、快闪、大促 |
| 静默锤击 | 长安静—强事件—更长安静—再击 | 恐怖、先锋、奢侈品 |

先按叙事目的选一条主曲线，不在同一短片里混合所有公式。

## 时间戳排布

每个阶段记录：时长、信息量、动作强度、景别、相机速度、声音强度和转折点。

示例，30 秒海浪式：

| 时间 | 功能 | 节奏 |
|---|---|---|
| 0–4 秒 | 钩子/建立 | 清晰、简短 |
| 4–10 秒 | 第一次推进 | 中等 |
| 10–16 秒 | 短暂回落 | 放慢、留反应 |
| 16–24 秒 | 主要升级 | 动作与声音增强 |
| 24–28 秒 | 高潮 | 最强画面或信息 |
| 28–30 秒 | 收束 | 简洁终止画面 |

## 镜头与节奏联动

- 景别：远景建立 → 中景行动 → 近景情绪/细节。
- 运动：固定/微移 → 缓推 → 跟拍/快速运动 → 停止。
- 声音：环境底噪 → 节奏元素加入 → 高潮 → 尾音或静默。
- 色彩：不随节奏随机换色；通过亮度、光比或局部高光递进。

## AI 片段后期对策

1. 生成时为剪辑点预留稳定姿态、视线、动作或环境声。
2. 检查每条素材起止处的形变、抖动和无意停顿；必要时裁去不稳定部分，但不机械固定裁 0.5–1 秒。
3. 选一条基准镜头统一曝光、白平衡、对比度、饱和度、肤色和颗粒。
4. 动作连续优先硬切或动作匹配；时间流逝可溶解；空间变化可用遮挡、甩镜或声音桥。
5. 不用快切掩盖关键剧情、产品错误或明显身份漂移；问题镜头应重做。
6. 为重要镜头生成备选，但素材量按风险决定，不机械要求 2–3 倍。

## 常用衔接锚点

- 动作：抬手、转头、落脚、开门、拿起产品。
- 视线：角色看向下一镜目标。
- 构图：同一主体在相同屏幕位置。
- 形状/颜色：圆形、竖线、相同色块。
- 遮挡：人物、门框、衣物、车辆扫过镜头。
- 声音：台词尾音、敲击、铃声、风声、音乐重拍。

每次转场优先一个主要机制，避免多种效果争抢。

## 声音与字幕

- 对白先保证可懂度和说话人一致，再铺音乐。
- 场景切换时保留短暂环境声桥，避免绝对静音断裂。
- 音乐卡点写具体时间点与动作，不只写“跟随节奏”。
- 字幕、精确标题和 Logo 后期添加；不要依赖模型生成大量准确文字。

## 交付内容

需要后期方案时输出：

1. 成片时间线与每镜入出点。
2. 主节奏曲线。
3. 镜头顺序与预计裁切。
4. 转场机制和共同锚点。
5. 声音桥、音乐点和静默段。
6. 统一调色和需重做的风险镜头。

## 自检

- 节奏是否服务情绪和信息，而非一味加速。
- 关键动作与对白是否有足够时间。
- 高潮前是否存在对比和积蓄。
- 转场方向、速度、颜色和声音是否连续。
- 是否把可修复问题留给后期，把身份/物理崩坏留给重生成。
