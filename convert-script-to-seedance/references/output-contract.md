# 输出契约

除非用户明确指定其他格式，最终结果使用下面的 Markdown 结构。所有表格与提示词的镜头 ID 必须一致。

## 1. 转换摘要

用 4–8 行说明：

- 识别到的内容类型与成片目标。
- 总时长、画幅、清晰度与风格。
- 选择的生成策略和生成单元数量。
- 最关键的素材依赖。

## 2. 假设与待确认项

使用三列：

| 项目 | 当前处理 | 依据/影响 |
|---|---|---|

没有不确定项时写“无”。不要为了提问而提问；先给出可执行版本。

## 3. 素材清单

使用以下字段：

| ID | Seedance 引用 | 状态 | 优先级 | 素材内容 | 用途与镜头 | 制作规格 |
|---|---|---|---|---|---|---|

约束：

- `Seedance 引用` 使用 `@图1`、`@视频1`、`@音频1` 这样的界面占位符。
- `状态` 只能为“已提供 / 待准备 / 可选”。
- `优先级` 只能为“必需 / 强烈建议 / 可选”。
- 同一物理素材只有一个 ID；不要在不同镜头重复登记。
- 纯文本可完成的镜头也要说明“无需外部素材”，避免用户误以为漏项。

## 4. 全局一致性设定

按项目实际情况列出：

- 视觉风格与色彩。
- 角色圣经。
- 场景与空间轴线。
- 产品/道具规则。
- 摄影与运动规则。
- 声音、对白和音乐规则。
- 全局禁止项。

所有描述都应可观察。不要只写“保持一致”。

## 5. 分镜计划

使用以下字段：

| 镜头 | 成片时间码 | 生成时长 | 模式 | 画面与动作 | 台词/声音 | 依赖素材 | 衔接点 |
|---|---|---:|---|---|---|---|---|

要求：

- 成片时间码连续，不重叠、不遗漏。
- 生成时长可以略长于剪辑使用时长，但必须说明裁切点。
- 台词逐字保留；为了时长拆分时，用省略号或停顿标记自然分界，不改台词含义。
- `衔接点` 明确上一镜或下一镜共同的动作、构图、声音或遮挡锚点。

## 6. 可直接复制的逐镜提示词

每个镜头一个独立代码块，不要把解释混进代码块：

### 镜头 S01｜短标题

参数：`时长｜画幅｜清晰度｜模式`

素材绑定：`@图1 = IMG-01，用于……；@音频1 = AUD-01，用于……`

```text
[只包含可粘贴到 Seedance 的完整提示词]
```

提示词内部顺序：

1. 素材分工。
2. 一句话镜头目标。
3. 人物、场景、光线、画幅与风格。
4. 按时间轴写动作和运镜。
5. 台词、旁白、动作声、环境声和音乐。
6. 结尾状态与下一镜衔接。
7. 与该镜相关的禁止项。

即使没有参考素材，也要在“素材绑定”写“无，纯文本生成”。

## 7. 生成与拼接顺序

给出简短可执行顺序，例如：

1. 先生成角色定妆与场景参考。
2. 先做承担视觉基准的镜头，再做相邻镜头。
3. 对口型镜头最后绑定最终音频重做。
4. 说明哪些片段应使用尾帧作为下一镜首帧。
5. 标出需在后期完成的字幕、Logo、精确包装文字或合成特效。

## 8. 风险与建议

只列实际存在的问题，并按“高 / 中 / 低”标级。典型风险包括：

- 复杂多人互动或高速动作。
- 一镜承载过多剧情。
- 台词时长与镜头时长不匹配。
- 缺少关键定妆、产品或声音参考。
- 精确文字、Logo、UI 依赖后期合成。
- 相邻镜头的服装、道具或光线存在冲突。

## 精简模式

用户明确要求“只给提示词”时，仍保留：

1. 一行关键假设。
2. 素材映射。
3. 每镜参数与完整提示词。
4. 严重风险提示。

不得把所有镜头压成一个难以执行的长段落，除非用户明确要求单条超长提示词。
