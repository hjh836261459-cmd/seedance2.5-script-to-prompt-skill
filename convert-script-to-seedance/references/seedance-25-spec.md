# Seedance 2.5 执行规格

本页是本 Skill 的参数真值表。若用户给出的平台界面显示不同限制，以用户当前界面为准，并在结果中说明差异。

## 输入与时长

| 类型 | 限制或建议 |
|---|---|
| 普通生成 | 4–30 秒 |
| 超长视频 | 30–180 秒 |
| 视频延长 | 原视频不超过 30 秒；新增 4–30 秒；合成结果最长 60 秒 |
| 图片 | 最多 30 张；优先清晰、主体无遮挡的 4K 图 |
| 视频 | 最多 10 条；单条 2–30 秒；全部视频总时长不超过 30 秒 |
| 音频 | 最多 10 条；单条 2–30 秒；全部音频总时长不超过 30 秒 |
| 纯音频输入 | 支持 |
| 清晰度 | 480p 或 720p；默认建议 720p |

## 稳定性建议

这些是实践建议，不是绝对硬限制：

- 音频或视频驱动时，主体数量优先 1–5 个，参考片段优先 5–10 秒。
- 图片驱动时，主体数量优先 1–8 个。
- 视频编辑源优先不超过 20 秒。
- 高级局部编辑优先使用 1–5 张清晰参考图。
- 复杂多人动作、连续形变、长对白和高速镜头会降低稳定性，应拆为更短镜头。

## 模式路由

| 剧本或任务特征 | 推荐模式 | 处理要点 |
|---|---|---|
| 只有文字或常规参考素材 | 普通多模态生成 | 拆成 4–30 秒单元 |
| 必须固定第一帧 | 首帧控制 | 将首帧作为构图与人物状态锚点 |
| 必须固定开头和结尾 | 首尾帧控制 | 中间动作必须解释从 A 到 B 的合理变化 |
| 单一连续事件、30–180 秒 | 超长视频 | 使用完整时间轴，减少角色和地点跳变 |
| 已有视频继续发展 | 视频延长 | 明确“在原视频之后延长”，锁定最后一帧状态 |
| 已有视频换人、换物、删改局部 | 智能编辑 | 清楚标出保留项、修改项、时间段 |
| 需要精细替换或局部控制 | 高级局部编辑 | 用 1–5 张参考图定义替换对象与边界 |
| 需要保留动作但换视觉风格 | 创意迁移 | 分开写动作参考和新风格设定 |
| 需要复刻镜头路径 | 运镜参考 | 指定参考视频只负责相机运动，不负责人物或场景 |
| 需要复刻声音 | 音色/音频参考 | 指定说话人、语种、语气、口型与音色用途 |
| 需要独立抠像素材 | 绿幕生成 | 纯色均匀背景、主体边缘清晰、无溢色 |
| 需要 3D 预演 | 粗白模/精白模 | 重点描述空间、机位、动作与镜头节奏 |
| 两段素材需要自然连接 | 无缝转场 | 描述共同运动、遮挡物、形状、颜色或音效锚点 |
| 一次展示多个镜头概念 | 多宫格分镜 | 写明网格布局和每格内容；最终成片仍建议逐格生成 |

## 参考素材绑定规则

提示词中的参考不是附件清单，而是执行指令。每次引用都必须包含：

1. 引用对象，例如 `@图1`。
2. 用途，例如“锁定女主五官、发型与红色风衣”。
3. 使用范围，例如“镜头 01–06”。
4. 不应继承的部分，例如“不要沿用参考图背景与文字”。

正确示例：

> 以 `@图1` 锁定女主的五官、短发和红色风衣，仅参考人物外观，不沿用图片背景；以 `@视频1` 只参考环绕运镜的速度和轨迹，不复制其中人物。

避免：

> 参考 `@图1` 和 `@视频1` 生成视频。

## 生成单元的复杂度预算

一个短生成单元建议只包含：

- 1 个核心叙事目标。
- 1 个主要地点。
- 1 次清晰情绪转折。
- 1 条主要运镜路径。
- 1–3 个连续动作节点。
- 一小段自然长度的对白或旁白。

超过预算时优先拆镜，不要单纯增加提示词长度。

## 连续性锚点

跨镜头至少复述与当前镜头有关的锚点：

- 人物：脸型、发型、服装、配饰、伤痕、手持物和情绪余韵。
- 场景：时间、光线方向、天气、空间方位和关键物体位置。
- 动作：上一镜结束姿态、视线方向、运动方向和速度。
- 声音：说话人音色、环境底噪、音乐节拍和前一镜尾音。

不要仅写“保持一致”；要指出保持什么一致。

## 2.5 专项能力清单

本 Skill 可以按剧本需要组合以下能力：

- 纯文本、首帧、首尾帧、多模态、纯音频驱动。
- 写实人物、动画角色、多人互动、动作和舞蹈。
- 4–30 秒普通生成、30–180 秒超长生成、精确时间戳控制。
- 一镜到底、视频延长、智能编辑、高级局部编辑。
- 去除 BGM、干净画面输出、指定旁白和对白。
- 创意迁移、视角改变、音色参考、绿幕生成。
- 粗白模、精白模、两视频无缝转场、多宫格分镜。
- 产品广告、短剧、教育科普、多语言内容。

不要加入“写实人脸不支持”等旧版 2.0 限制。
