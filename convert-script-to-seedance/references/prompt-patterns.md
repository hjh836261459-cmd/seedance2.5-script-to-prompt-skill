# 专项提示词模式

只读取与当前项目有关的章节，并把方括号占位符替换成具体内容。模板用于组织信息，不应机械照抄。

## 基础多模态镜头

```text
以@图1锁定[角色/产品]的[具体特征]，仅参考[范围]，不沿用[不需要的背景/文字]；以@视频1只参考[动作/运镜]，不复制[人物/场景]；以@音频1作为[角色/旁白]的音色与节奏参考。

[时长]秒，[画幅]，[风格]。[主体]在[时间与场景]完成[核心动作和叙事目标]。[光线、色彩、质感与空间关系]。

0–[x]秒：[景别、机位、动作、运镜、焦点和声音]。
[x]–[y]秒：[下一动作、情绪变化、运镜与声音]。
[y]–[结束]秒：[收束动作、结尾构图和下一镜衔接点]。

[说话人]用[语气]说：“[台词]”。保留[环境音/动作声]，[音乐要求]。保持[人物/产品/场景锚点]一致。不生成[与本镜相关的禁止项]。
```

## 30 秒叙事镜头

把 30 秒划成 4–7 个清晰阶段，每段只推进一件事：建立场景、触发事件、人物反应、主要行动、转折、收束。台词落在具体时间段，并为反应和停顿预留时间。

```text
生成30秒连续视频，[画幅/风格/一致性设定]。
0–4秒：[建立镜头]。
4–9秒：[触发事件]。
9–15秒：[人物反应与台词]。
15–22秒：[主要行动与运镜]。
22–27秒：[转折或结果]。
27–30秒：[结尾状态与衔接]。
[完整声音设计与禁止项]。
```

## 30–180 秒超长视频

超长视频适合少地点、少人物、连续空间中的完整事件。每 10–20 秒设置阶段锚点，并在阶段之间重申角色状态和场景连续性。

```text
生成[总时长]秒连续视频，[画幅/风格]。全程保持[角色外观、服装、道具、空间轴线、光线方向、声音]一致。
0–15秒：[开场事件]。
15–30秒：[发展]。
30–45秒：[发展]。
……
[结束前一段]：[高潮或结论]。
[最后一段]：[收束与最终画面]。
段落切换通过[动作/视线/遮挡/声音]自然衔接，不瞬移、不换装、不无故改变时间天气。[声音和禁止项]。
```

若地点或角色状态发生重大变化，优先改为逐镜生成，不使用超长模式硬做。

## 一镜到底

```text
生成[时长]秒一镜到底视频，全程无剪切、无跳帧、无瞬移。相机从[起始位置与景别]开始，沿[明确路径]以[速度]移动，依次经过[空间节点]，始终保持[主体]的空间连续性和动作因果。焦点从[对象A]自然转移到[对象B]，最后停在[结尾构图]。[对白、环境音和禁止项]。
```

路径过于复杂时拆为多个“伪一镜到底”镜头，并用遮挡转场拼接。

## 首尾帧控制

```text
以@图1作为第一帧，严格保持[起始构图、人物姿态、光线]；以@图2作为最后一帧，严格达到[结束构图、人物状态、物体位置]。在[时长]秒内，让[主体]通过[连续动作链]从第一帧自然变化到最后一帧。相机[运镜路径]，变化过程符合物理逻辑，不突然变形、不瞬移。[声音设计]。
```

## 视频延长

```text
在@视频1结束后继续延长[新增时长]秒。以原视频最后一帧为连续起点，保持[人物外观、服装、姿态、运动方向、相机速度、焦距、光线、环境声]不变。随后：[按时间轴描述新增动作和剧情]。不要重演原片段，不要跳回较早状态，最终停在[结尾画面]。
```

## 智能编辑与局部替换

```text
编辑@视频1。必须保留：[镜头运动、时间长度、背景、未修改人物、原始声音等]。仅在[时间段/画面区域]把[原对象或属性]修改为[目标对象或属性]；以@图1锁定替换后对象的[外观特征]。替换对象要继承原对象的[动作、透视、光照、遮挡和运动模糊]。其他区域不改变，不新增元素。
```

若要去除 BGM：明确“移除背景音乐，保留对白、环境声和动作声；缺失的环境底噪自然补齐，不改变口型节奏”。

## 动作、舞蹈与运镜复刻

```text
以@视频1只参考[人物动作/舞步]的节奏、幅度和时间点，不复制其人物、服装和背景；以@视频2只参考相机的[轨迹、速度、焦距变化]。让@图1中的角色在[场景]完成对应动作，保持角色脸部、服装和肢体比例稳定。动作与[音乐/节拍]在[具体时间点]卡点，[结尾姿势]作为下一镜衔接。
```

复杂动作拆成起势、发力、腾空/转向、落地和定格，分别说明重心与方向。

## 多人对话短剧

```text
[时长]秒，[场景与人物站位]。A位于[位置]，B位于[位置]，保持视线轴和左右关系稳定。
0–[x]秒：A做[动作]，看向B，用[语气]说：“[台词]”；B只做[反应]，不说话。
[x]–[y]秒：镜头[切换/移动]到B，B用[语气]说：“[台词]”；A保持[动作]。
[y]–[结束]秒：[反应与结尾]。
两人的音色分别绑定[音频参考]，口型对应各自台词，不串词、不抢话、不改变站位。
```

台词密集时优先拆为正反打镜头，后期拼接比单镜多人对话稳定。

## 产品广告

```text
以@图1锁定产品的外形、材质、比例、Logo位置和包装颜色，不改字、不变形。生成[时长]秒[画幅]广告。
0–[x]秒：[需求/痛点或氛围建立]。
[x]–[y]秒：[产品出场，镜头路径与高光变化]。
[y]–[z]秒：[核心功能演示，手部与产品交互]。
[z]–[结束]秒：[英雄镜头与结尾构图]。
材质反射符合[环境]，关键卖点用可见动作表现。包装精确小字与最终 Logo 建议后期叠加；画面中不生成随机文字。
```

## 教育科普

```text
用[时长]秒解释[概念]，目标受众为[受众]。先用[生活化问题]建立直觉，再展示[可视化过程]，最后用[一句结论]收束。每个因果关系按顺序出现，不跳步。旁白：“[旁白原文]”。画面只出现与当前句对应的对象；公式、精确标签和大量文字留给后期叠加，不生成伪文字。
```

## 音色与纯音频驱动

```text
以@音频1作为[角色/旁白]的内容、音色、语速、情绪和停顿依据。画面中的[人物]在对应语句出现时自然口型同步；无台词处保持自然呼吸与微表情。根据声音中的[节拍/情绪变化/关键词]安排[动作、切换或运镜]。不改变原音频内容，不添加无关说话人。
```

若音频只用于音色而不用于文案，要明确“只参考音色，不沿用原音频台词”。

## 绿幕素材

```text
生成[主体]的独立绿幕素材，[时长]秒，固定[景别/机位]。背景为均匀纯绿色，无渐变、无阴影、无纹理。主体完成[动作]，全身/边缘始终完整清晰，头发与半透明区域细节稳定，无绿色溢色。相机[固定或明确运镜]，不添加地面杂物、字幕或其他对象。
```

## 粗白模与精白模

粗白模用于验证空间和机位：

```text
生成无材质白模预演，重点准确呈现[空间布局、人物走位、物体尺度、相机路径和节奏]。所有对象使用中性白色，不需要纹理与成品灯光，不改变空间轴线。
```

精白模用于验证轮廓和动作：

```text
生成高精度白模预演，保留[角色轮廓、服装体块、产品结构、手部接触、遮挡关系]，使用中性白色材质和清楚柔光。严格执行[动作与运镜时间轴]，不添加最终贴图与装饰。
```

## 两段视频无缝转场

```text
以@视频1作为前段，以@视频2作为后段，在[转场时长]秒内无缝连接。前段结尾的[共同运动/形状/颜色/遮挡物/音效]作为转场锚点，通过[具体转场机制]自然变为后段开头的[对应元素]。保持运动方向和速度连续，不出现黑帧、闪断、重影或主体形变。
```

可选机制：动作匹配、遮挡擦镜、形状匹配、颜色匹配、推进穿越、拉远揭示、甩镜、焦点转换、光闪、物体变形、声音桥接。每次优先使用一种主机制，避免多种效果互相争夺。

## 多宫格分镜预览

```text
生成[2×2/3×3]多宫格分镜预览，每格边界清晰、编号明确但不生成复杂文字。第1格：[内容与景别]；第2格：[内容与景别]；……。所有格保持[角色、服装、场景、色彩]一致，仅用于确认构图与镜头顺序。正式生成时将每格分别转为独立镜头。
```

## 多语言内容

```text
[角色]使用[语言/口音]自然说：“[原文台词]”，语气[描述]，语速[描述]，口型与该语言发音同步。场景中的非必要文字不生成；需要显示的翻译字幕在后期添加。专有名词按[指定读法]发音。
```

不要擅自翻译用户指定保留的台词；若需要双语版本，为每个语言建立独立提示词和音频素材。
