# 剧本转 Seedance 2.5

把剧本编译成可以直接执行的 Seedance 2.5 生成方案。默认交付逐镜提示词和素材需求；不修改原剧本，不虚构用户已经拥有的素材。

## 开始前读取

每次执行都先读取：

- `references/seedance-25-spec.md`：参数、输入限制和模式路由。
- `references/output-contract.md`：固定交付结构和字段。

遇到转场、续写、视频编辑、音色复刻、绿幕、白模、多宫格、超长视频等专项需求时，再读取 `references/prompt-patterns.md` 中对应章节。不要沿用 Seedance 2.0 的旧限制。

## 工作流

### 1. 接收并保护原始剧本

- 用户直接粘贴文本时，以该文本为唯一原稿。
- 用户给出 `.txt` 或 `.md` 路径时，直接读取。
- 用户给出 `.docx` 时，按文档读取流程提取正文；给出 `.pdf` 时，按 PDF 读取流程提取正文并在必要时核对渲染页。
- 若同时存在剧本与补充要求，补充要求的优先级高于默认值，但不能悄悄改写明确的台词、角色关系或情节结果。
- 仅当文件无法访问、文本无法辨认或缺失会导致完全不同的成片方案时才提问。其他缺项先做合理推断，在“假设与待确认项”里注明。

### 2. 解析剧本事实

提取并规范化以下内容：

- 片名、用途、目标平台、画幅、总时长、风格和受众。
- 角色：稳定外观、年龄段、服装、声音、关系、不可变化特征。
- 场景：时间、地点、天气、光线、空间布局和连续性锚点。
- 道具、产品、界面、文字、品牌标志和必须准确出现的元素。
- 每场的动作、情绪、台词、旁白、环境音、音乐和剧情转折。
- 用户已经提供的图片、视频、音频，以及每份素材真正可承担的唯一用途。

明确区分“剧本明示”“根据上下文推断”“创作性补全”。不要把推断写成用户事实。

### 3. 制定生成策略

默认使用“逐镜生成、后期拼接”，因为它最利于角色一致性和返工。按以下顺序判断：

1. 原有视频只需修改：选择智能编辑或高级局部编辑。
2. 原有视频需接着演：选择视频延长。
3. 需要固定开头与结尾构图：选择首尾帧控制。
4. 单一连续事件、空间关系简单且用户需要长成片：可选择超长生成。
5. 其他情况：拆为 4–30 秒的普通生成单元；复杂镜头优先 6–12 秒，简单叙事可用 12–20 秒。

拆镜时遵守：

- 一个生成单元只承载一个主要叙事目标。
- 每次只安排可清楚完成的动作与运镜；不要把多个地点、多个情绪转折和复杂对白硬塞进同一短镜头。
- 在切分点保留动作、视线、道具位置、光线和环境音的衔接信息。
- 对话不能跨镜丢失说话人；台词较长时按自然停顿拆分。
- 若采用超长生成，仍按时间段写清事件和连续性，而不是输出一个松散段落。

### 4. 建立素材台账

先规划素材，再写提示词。为每项素材分配在整个项目中唯一且不复用的 ID：

- 图片：`IMG-01`、`IMG-02`……
- 视频：`VID-01`、`VID-02`……
- 音频：`AUD-01`、`AUD-02`……

每项素材必须写明：状态、优先级、内容、用于哪些镜头、用途和拍摄/制作规格。状态只能是“已提供”“待准备”“可选”；优先级只能是“必需”“强烈建议”“可选”。

素材规划原则：

- 同一角色优先使用统一定妆照或多视角角色参考，不为每镜随意换图。
- 场景、产品、关键道具、动作、运镜、转场、音色分别建立参考；一份参考不要承担含糊的多个职责。
- 只有纯文本足以表达且一致性风险低时，才将参考素材标为可选。
- 用户未提供素材时照常完成方案，以“待准备”占位，不宣称素材存在。
- 每个 `@` 引用后立刻说明用途，例如“以 `@图1` 锁定女主外观”，不能只写“参考 `@图1`”。

### 5. 编译逐镜提示词

每条提示词按下列顺序组织：

`素材分工 + 一句话镜头目标 + 全局设定 + 时间轴动作与运镜 + 台词/声音 + 连续性要求 + 禁止项`

写作要求：

- 用具体、可见、可听、可计时的描述，避免“高级感”“电影感拉满”等空泛词。
- 明确主体、动作方向、速度、镜头尺度、机位、运动路径、焦点和光线变化。
- 有多段事件时用 `0–3秒`、`3–7秒` 等时间轴；短单动作镜头可用自然语言顺序。
- 保留剧本中的台词原文，标注说话人、语气、停顿和是否画外音；不要让旁白和角色口型混淆。
- 声音至少说明环境音；仅在剧情需要时添加 BGM。未要求字幕时默认“不生成字幕、贴纸、水印和无关文字”。
- 在每条提示词中重申该镜头真正需要的角色与场景锚点；不要用“同上”代替关键一致性信息。
- 同一镜头中出现多个参考时，逐项绑定用途。没有使用的素材不要附带。

### 6. 做两轮质量检查

第一轮检查计划：

- 所有剧本场次、台词和关键动作都有归属。
- 镜头时长之和与目标成片时长一致，或明确说明剪辑后时长。
- 生成模式与 2.5 的时长、素材数量和素材时长限制兼容。
- 每项必需素材至少被一个镜头引用，每个引用都能追溯到素材台账。

第二轮检查提示词：

- 没有相互冲突的景别、动作方向、时间、天气和角色状态。
- 单镜任务量可实现，转场不会破坏人物或产品形态。
- 角色外观、服装、道具、空间轴线、对白声音和画幅保持连续。
- 代词指向清楚，多人镜头写明谁做什么、谁说什么。
- 禁止项只保留与当前镜头有关的风险，不堆叠无意义负面词。

发现问题时直接修订方案，再在“风险与建议”中列出仍无法消除的风险。

### 7. 按固定结构交付

严格使用 `references/output-contract.md` 的顺序输出。至少包括：

1. 转换摘要。
2. 假设与待确认项。
3. 素材清单。
4. 全局一致性设定。
5. 分镜计划。
6. 可直接复制的逐镜提示词。
7. 拼接与生成顺序。
8. 风险与建议。

即使素材尚未准备，也必须交付完整的占位版提示词。用户要求精简版时，可以省略说明文字，但不能省略素材绑定、逐镜提示词或关键假设。

## 默认值

剧本没有提供必要参数时采用以下默认值，并明确标注为推断：

- 社交平台、短剧、电商口播：`9:16`；电影化叙事、横版广告、教育片：`16:9`。
- 输出清晰度：`720p`。
- 普通生成单元：优先 `6–12秒`，依据动作复杂度调整，始终保持在 `4–30秒` 内。
- 语言：台词原语言；提示词用中文，专有名词保持原文。
- 画面文字：默认无字幕、无水印、无随机文字；剧本明确要求的标题、UI 或包装文字除外。
- 声音：保留对白、动作声和环境声；BGM 只有在剧本指定或明显需要节奏设计时加入。

## 用户可用的调用方式

- “用这个 Skill 处理 `D:\项目\剧本.docx`。”
- “把下面的三分钟短剧拆成 Seedance 2.5 提示词，竖屏，角色必须一致。”
- “我只有角色定妆照和配音，请列出还缺什么素材并生成占位提示词。”
- “不要拆镜，按 90 秒超长视频模式转换这份科普脚本。”
